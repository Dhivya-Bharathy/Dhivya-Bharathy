## About me

I'm an **AI Software Developer** who builds **intelligent agents**, demos, and developer tools — mostly with **TypeScript**, **Python**, and the **OpenAI** APIs. I work with the [**Praison**](https://github.com/MervinPraison/praisonai) ecosystem and I'm deepening **GraphQL** + **Apollo Client** for production frontends.

**What I'm doing now**

- Shipping **multi-step AI agents** (tools, memory, workflows)
- Prototyping **voice-first UIs** (ChatGPT-style flows, STT/TTS, scripted comedy demos)
- Learning **Apollo Client**, schema design, and typed data layers
- Growing **[@theaipaithiyam](https://instagram.com/theaipaithiyam)** — Tamil / Tanglish AI skits, reels, and “what if ChatGPT…” experiments

**How I like to work**

- Early 🐤 · strongest on **Fridays**
- Iterate fast in **VS Code**, ship via **GitHub** / **Vercel**
- Document in public; break things on purpose in sandbox repos
